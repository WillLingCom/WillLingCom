
# Hi, I'm Will Ling 👋

### Building AI Agents for the Physical World

I'm a tech founder, maker, and open-source enthusiast exploring how AI agents can interact with the real world.

Currently, I'm the Co-founder & CTO of [Deotaland](https://github.com/Deotaland), where we're building an open Physical Agent platform.

**My belief:** AI agents shouldn't live only on screens. They should be able to see, hear, move, and interact with the physical world.

## 🚀 What I'm Building

- **Physical AI** — Bringing AI agents into real-world devices.
- **Robotics** — Exploring embodied interaction, perception, and motion.
- **Open Hardware** — Making it easier to connect hardware to different AI agents.
- **AI × IoT** — Bridging intelligent software and physical devices.

## 🛠 Featured Projects

### [Deotaland Agent Link](https://github.com/Deotaland/Agent_link)

### Rorolee — Pocket AI Device
